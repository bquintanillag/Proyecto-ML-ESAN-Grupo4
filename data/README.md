# Datos

Este proyecto no requiere descargar un dataset externo.

El archivo `notebooks/Proyecto_Final_ML_Optimizacion_Bayesiana_ESAN.ipynb` genera desde cero un dataset **100% sintético** de 50,000 interacciones utilizando una semilla fija (`SEED = 42`).

No se versiona `dataset_sintetico.csv` para evitar duplicar un archivo generado automáticamente. Al ejecutar el notebook completo, el CSV puede volver a crearse con los mismos supuestos del generador.

**Importante:** durante la revisión final no se modificaron las hipótesis ni los coeficientes del generador sintético original.
